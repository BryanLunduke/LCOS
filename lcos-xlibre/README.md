# LCOS XLibre (`+lcos1`)

LCOS rebuilds / vendors XLibre for the signed overlay so installed systems do
**not** use `xlibre-deb.github.io`.

- Upstream: https://github.com/X11Libre/xserver (and related)
- Binary packages: https://lcos.lunduke.com/apt (versions `*+lcos1`)
- Notes: `XLIBRE.md`, `XLIBRE-UNOFFICIAL.md`
- Checksums for the 0.3 overlay XLibre debs: `SHA256SUMS`

This directory documents the LCOS packaging relationship. Full upstream source
remains with X11Libre; LCOS ships rebuilt/metapackage debs on the overlay.
